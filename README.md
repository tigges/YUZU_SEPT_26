A version gallery for Yuzu Hair at Dickens Yard, Ealing.

Live: https://tigges.github.io/YUZU_SEPT_26/

- Home: version gallery
- `?v=earthy` parchment / olive site
- `?v=instagram` built from [@yuzuhairandbeauty](https://www.instagram.com/yuzuhairandbeauty/)

- `?v=sanctuary` forest / gold “Sanctuary” prototype from [YUZU_V4_CURSOR](https://github.com/tigges/-YUZU_V4_CURSOR)

## Run locally

```bash
npm install
npm run dev
```

Production build (also prepares GitHub Pages files):

```bash
npm run build:pages
```

GitHub Pages serves the compiled `index.html` and `assets/` from the `main` branch. Local development uses `dev.html`.
