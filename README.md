# Yuzu Hair & Beauty — earthy redesign

A focused single-page site for Yuzu Hair at Dickens Yard, Ealing. It keeps the salon’s real copy, prices, offers, and photography, and rebuilds the layout as a calm, modern earthy page.

## Design

- **Palette:** parchment, sage olive, terracotta, deep forest — warmer than the current Wix site, less generic than a pure white/red template.
- **Type:** Cormorant Garamond for the YUZU wordmark and headings; Outfit for UI.
- **Brand art:** line portraits and leaf drawings from the live price list; foliage photography from the live hero; customer work from the v1-clean gallery.

## Page structure

1. Sticky header with Book CTA  
2. Patch-test notice  
3. Hero banner + Book appointment  
4. Customer gallery + social links  
5. Google review teasers  
6. Services  
7. Prices (senior / stylist) + treatments  
8. Offers and loyalty packages  
9. Address, hours, map  

Booking stays on Phorest. Reviews and the map open Google.

## Run locally

```bash
npm install
npm run dev
```

Production build: `npm run build`.
